Classes

CMPSC 3323 - Internet Programming

This class teaches how to build web pages using HTML, CSS, and related web technologies. We learn to structure content, apply styles, and create interactive experiences on the web.

This class covers how data is stored, organized, and accessed efficiently. Topics include arrays, linked lists, stacks, queues, trees, and sorting algorithms.

This class focuses on foundational computer skills including operating systems, productivity software, file management, internet safety, and basic programming concepts.
